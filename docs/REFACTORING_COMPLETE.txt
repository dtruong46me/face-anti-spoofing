## 🚀 How to Use

### Training
```bash
python run_training.py --modelname "feathernet" --max_epochs 40
```

### Single Image Prediction
```bash
python predict_sample.py --image "test.jpg" --modelname "feathernet"
```

### Real-time Video Detection
```bash
python run_video_inference.py --modelname "feathernet"
```

### Programmatic Usage
```python
from src.predictor import FASPredictor

predictor = FASPredictor("model.ckpt", "feathernet")
result = predictor.predict_from_path("test.jpg")
print(f"Result: {result['label']} ({result['probability']:.2%})")
```
